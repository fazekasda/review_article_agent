# review_article_agent

An AI-assisted, evidence-grounded scientific review writer.

No production application features exist yet. Implementation step 00 (the
OpenCode integration and language spike) has produced throwaway prototypes under
`spikes/runtime/`, a **partial** handoff, and a **proposed** (not approved)
runtime-language decision. The technology stack is not ratified.
