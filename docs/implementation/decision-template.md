# Decision record template

Copy this template to `docs/decisions/NNN-<topic>.md` when a real decision is made.

## Status

Proposed / accepted by user / superseded. Include date and approving authority. A recommendation is not approval.

## Context and constraints

Link the affected specification clauses, implementation step, evidence, and actual versions tested.

## Options and evidence

Describe alternatives, experiments, limitations, operational cost, and unknowns. Separate documentation claims from observed behavior.

## Decision

State the choice, scope, defaults, failure policy, and what is explicitly not decided.

## Consequences and verification

Identify migrations, invalidated approvals/results, compatibility, tests, and conditions for revisiting the choice.

## Handoff

Link implementation/handoff evidence and unresolved follow-up work. Never include secrets or unnecessary licensed full text.
