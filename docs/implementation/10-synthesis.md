# 10 — Cross-paper synthesis, framework, outline, and argument record

## Dependencies

09 and ratified framework contract from 01.

## Deliverables

- Evidence map and synthesis memo with human approval.
- Relationships among reports/studies/experiments, applicability, limitations, contradictions, independent evidence and gaps.
- Scientific framework and actual outline proposals, separate from the early scope map and Jev rubric.
- Shared approved definitions, relationships/directionality, scope constraints, and unresolved questions.

## Acceptance criteria

- A fixture with several reports of one dataset is not counted as several independent confirmations.
- Preserve genuine disagreement; distinguish species/outcome differences, null evidence, and insufficient data. Publication/significance counts or model votes cannot select the conclusion.
- Trace synthesized statements to findings and sources; identify new interpretation separately from reported evidence.
- Framework/outline approval cannot precede accepted synthesis. Include contribution/admission/support/revision fields if P1 was ratified; do not silently omit an approved field or enforce a deferred one.
- User edits create revisions and impact reports. Changed definitions/relationships flag dependent sections.
- No need to generate manuscript tables or figures, but relationships used in the prose remain inspectable internally.
- Frameworks remain proposals unless justified as established knowledge; a polished taxonomy is not automatically scientific novelty or consensus.

## Handoff

Include a representative approved synthesis/outline, contradictory-evidence cases, and artifact dependency tests. Section blueprint generation must use these approved revisions, not unrecorded planner chat.
